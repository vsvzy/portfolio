# 최민성의 자기소개 사이트

골프와 음악을 좋아하는 최민성을 소개하는 React + JavaScript + Vite 사이트입니다.
첫 화면에는 한 줄 소개, 관심사, 강점과 배움·목표를 위한 준비 공간, 활동과 작품 공간이 있습니다.
짙은 배경, 연두색·보라색 강조, CSS로 만든 구와 고리를 사용해 미래적인 디지털 미술관처럼 꾸몄습니다. 휴대전화에서는 카드가 한 줄로 배치됩니다.
자기소개 메뉴·버튼은 별도의 자기소개 페이지(`#/about`)로, 활동과 작품 메뉴·버튼은 목록 페이지(`#/portfolio`)로 이동합니다.
각 페이지에서 홈으로 돌아가기와 브라우저 뒤로 가기·새로고침을 사용할 수 있습니다.
실제 활동과 작품은 아직 등록하지 않았습니다. 이전 예시 작품 주소는 찾을 수 없다는 안내를 표시합니다.
관심사는 `src/App.jsx`의 `interests`에서 수정하며, 강점·배우고 싶은 것·목표는 `GrowthCards`에서 수정합니다.
사진과 작품을 추가할 때는 `ActivityPlaceholder`를 실제 콘텐츠로 바꾸고 목록과 작품 수를 함께 갱신합니다.

## 내 프로젝트로 시작하기

1. GitHub의 **Use this template → Create a new repository**로 자신의 저장소를 만듭니다.
2. 새로 만든 저장소를 컴퓨터로 복제하고 Visual Studio Code에서 엽니다.
3. 아래 실행 방법에 따라 사이트를 실행합니다.
4. GitHub Copilot과 함께 자기소개, 프로젝트 설명, 색상과 이미지를 자신의 내용으로 바꿉니다.

아직 알려지지 않은 강점·활동·목표는 ‘준비 중’으로 표시합니다. 실제 경험을 확인한 뒤 채우고, 전화번호·주소·생년월일은 넣지 않습니다.

## 실행하기

1. Node.js 24 LTS를 설치합니다.
2. Visual Studio Code에서 복제한 프로젝트 폴더를 엽니다.
3. 터미널에서 다음 명령을 실행합니다.

```sh
npm install
npm run dev
```

터미널에 표시되는 주소를 브라우저에서 엽니다. 개발 서버는 `Ctrl + C`로 종료합니다.

## 수정할 파일

- `src/App.jsx`: 화면 내용과 React 컴포넌트
- `src/App.css`: 화면 스타일
- `src/index.css`: 전체 공통 스타일
- `public/`: 직접 사용할 이미지 등 정적 파일

파일을 수정하고 저장하면 실행 중인 브라우저에 반영됩니다.

## 확인 명령

```sh
npm run lint
npm run build
```

`npm run build`는 배포용 파일을 `dist` 폴더에 만듭니다.
